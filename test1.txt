Basic Git Commands:
1. `git init` - Initialize a new Git repository.
2. `git clone <repository-url>` - Clone an existing repository.
3. `git status` - Check the status of your working directory.
4. `git add <file>` - Stage changes for commit.
5. `git commit -m "message"` - Commit staged changes with a message.
6. `git push` - Push changes to a remote repository.
7. `git pull` - Fetch and merge changes from a remote repository.
8. `git branch` - List, create, or delete branches.
9. `git checkout <branch>` - Switch to a different branch.
10. `git merge <branch>` - Merge a branch into the current branch.
